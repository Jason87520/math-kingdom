# 数学王国探险

一个面向小学五年级的纯前端数学情境解题游戏。小英雄要穿过 **新手林、进阶谷、智慧峰** 三张地图，用小数、方程、因数倍数、面积、体积和经典应用题，打败糊涂魔王，找回数学王国的光。

- 无需后端、无需登录、无需安装依赖
- 双击 `index.html` 就能玩
- 进度、金币、爱心、星星、错题本、地图解锁都保存在当前浏览器的 `localStorage`
- 手机、平板、电脑都能用，竖屏优先，按钮和字号偏大
- 全部界面为中文，题目语言按五年级阅读水平编写

---

## 1. 本地打开

### 最简单的方式

直接双击项目根目录的 `index.html`。

项目使用普通 `<script>` 标签加载脚本，没有使用 ES Module，所以 `file://` 方式也能运行。

### 推荐方式：本地静态服务器

如果浏览器对 `file://` 的本地存储限制较严，可以在项目目录打开终端：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

也可以使用 VS Code 的 Live Server 插件。

> 首次点击页面后才会启用音效，这是浏览器的自动播放限制。朗读功能取决于系统是否安装了中文语音包。

## 2. 怎么玩

1. 从首页进入地图，按顺序闯关。
2. 每关先读一段情境故事，再开始答题。
3. 答对后获得星星、金币和经验，并显示完整讲解。
4. 第一次就答对得 3 星，第二次得 2 星，第三次及以后得 1 星。
5. 每关 3 颗爱心，答错扣 1 颗。爱心用完不会结束游戏，而是回到本关开头重新开始。
6. 答错的题会自动进入「魔法书」。在魔法书里复习并答对，就能净化这道题，并获得少量金币和经验。
7. 完成一张地图的全部关卡后，下一张地图自动解锁。
8. 三张地图全部完成后，可以观看王国大结局。

### 星星与奖励

| 情况 | 星星 | 首次通关金币 | 首次通关经验 |
| --- | --- | --- | --- |
| 第一次答对 | 3 星 | 25 | 45 |
| 错 1 次后答对 | 2 星 | 20 | 35 |
| 错 2 次及以上后答对 | 1 星 | 15 | 25 |
| 使用跳过卡 | 0 星 | 0 | 0 |

重玩只刷新最高星级，不会重复发放金币和经验。复习错题答对会净化错题，并获得 10 金币、15 经验。

### 商店

| 道具 | 价格 | 作用 |
| --- | --- | --- |
| 提示卡 | 20 金币 | 直接展开下一步提示，不扣爱心 |
| 时光沙漏 | 15 金币 | 10 秒大字回顾题意并朗读，不扣爱心 |
| 跳过卡 | 60 金币 | 跳过本关，0 星，展示讲解并解锁下一关 |

初始拥有 30 金币、1 张提示卡、1 个时光沙漏。

## 4. 题库格式

内置题库在 `js/questions.js`，是一个数组：

```js
window.QUESTION_BANK = [
  {
    id: "dec-001",
    map: "forest",
    type: "decimal",
    title: "星光文具店",
    scene: "小松鼠在星光文具店买了 4 瓶墨水，每瓶 3.5 元。它付给山羊老板 20 元。",
    question: "山羊老板应该找回多少元？",
    answer: 6,
    unit: "元",
    answerType: "number",
    hints: [
      "第一步：4 瓶墨水一共多少钱？",
      "用乘法算总价：3.5 × 4 = 14（元）。",
      "第二步：付了 20 元，找回多少？20 − 14 = 6（元）。"
    ],
    explain: "先算总价：3.5 × 4 = 14（元）。再算找回：20 − 14 = 6（元）。所以应找回 6 元。"
  }
]
```

### 字段说明

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 是 | 唯一编号，不能与内置题或其它自定义题重复 |
| `map` | 是 | `forest` / `valley` / `summit` |
| `type` | 是 | `decimal` / `equation` / `factors` / `area` / `solid` / `classic` |
| `title` | 建议 | 关卡标题，会显示在关卡节点和故事页 |
| `scene` | 是 | 情境故事，先于问题显示 |
| `question` | 是 | 要问的问题 |
| `answer` | 是 | 数值题的答案填数字；选择题填选项原文 |
| `unit` | 是 | 答案单位，没有单位可填空字符串 |
| `answerType` | 否 | `number`（默认）/ `equation` / `choice` |
| `options` | 选择题必填 | 选项数组，`answer` 必须出现在其中 |
| `hints` | 是 | 分步提示数组，至少 2 条；孩子答错时会逐条展开 |
| `explain` | 是 | 答对后展示的完整讲解 |
| `subtype` | 可选 | 经典应用题的细分类，如 `chicken-rabbit` / `planting` / `travel` |
| `diagram` | 可选 | 图形示意数据，支持 `parallelogram` / `triangle` / `trapezoid` / `cube` / `cuboid` / `rectangle` |

### 答案输入方式

- `number`：数字键盘输入，支持小数。
- `equation`：显示 `x =`，孩子只输入数值部分。
- `choice`：显示选项按钮，不需要数字键盘。

### 图形示意示例

```js
diagram: {
  shape: "triangle",
  base: 10,
  height: "?",
  unit: "厘米"
}
```

高度为 `"?"` 时会显示问号，适合“已知面积求高”一类题目。

## 5. 添加题目

### 方式一：直接改题库文件

1. 打开 `js/questions.js`。
2. 在数组末尾添加一道题，确保 `id` 唯一。
3. 检查 `hints` 至少 2 条，`explain` 不为空。
4. 刷新页面，进入对应地图的最后即可看到新题。

注意：直接改文件新增的题目会排在所属地图末尾。如果它影响地图完成度，可能改变地图解锁判断。

### 方式二：家长 / 老师模式里添加

进入「家长 / 老师模式」→「题库」→「＋ 新增题目」，填写：

- 地图、知识点、标题
- 情境故事、问题
- 答案输入方式与答案、单位
- 选择题选项（一行一个）
- 至少 2 条分步提示（一行一条）
- 讲解

保存后会写入浏览器的 `mathKingdom.custom.v1`，不会修改 `questions.js`。自定义题目默认排在所属地图最后，不支持图形配图。

内置题不能直接编辑，但可以隐藏。隐藏会改变关卡数量和地图完成度，请谨慎操作。

## 6. 家长 / 老师模式

入口：首页底部「家长 / 老师」。

默认密码：

```text
8888
```

进入后可以：

- 查看总览：已点亮关卡、总作答次数、首次答对率、平均每题用时、累计学习时间、错题数、等级、金币
- 查看最近 7 天作答柱状图
- 查看各知识点的作答、答错、首次答对率、完成数、平均用时
- 查看并移除错题
- 查看题库、隐藏 / 显示题目、新增 / 编辑 / 删除自定义题
- 导出存档、导入存档
- 修改家长密码
- 重置全部进度（自定义题库、设置和密码会保留）

建议在重置或导入前先点「导出存档」。导出的 JSON 同时包含游戏进度和自定义题库。

## 7. 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库，例如 `math-kingdom`。
2. 把 `math-kingdom` 文件夹里的所有文件上传到仓库根目录。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 里选择：
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. 保存后等待一两分钟，访问：

```text
https://你的用户名.github.io/math-kingdom/
```

项目没有构建步骤，也没有后端依赖，直接静态托管即可。

> 如果部署在子路径下，请保持 `index.html` 里的 CSS / JS 相对路径不变（当前已经是相对路径）。

## 8. 存档说明

使用的键：

```text
mathKingdom.save.v1     游戏进度
mathKingdom.custom.v1   自定义题库
```

保存的内容包括：金币、爱心、经验、星星、跳过记录、已解锁地图、当前关卡、错题本、道具、统计、设置、家长密码、隐藏题目、结局观看状态。

注意事项：

- 存档只保存在当前浏览器、当前站点下，不会自动同步到其它设备。
- 清理浏览器数据、换浏览器、换设备后，进度不会自动带过去。
- 换设备前请先在家长模式导出存档，再在新设备导入。
- 使用 `file://` 打开时，不同浏览器对本地存储的处理可能不同；长期使用建议用本地静态服务器或 GitHub Pages。

## 9. 浏览器支持

建议使用较新的 Chrome、Edge、Safari 或 Firefox。

- 音效使用 WebAudio 现场合成，不需要音频文件。
- 中文朗读使用浏览器 `speechSynthesis`；没有中文语音包时，朗读按钮会提示不可用，不影响答题。
- 支持 `prefers-reduced-motion`，也可以在设置里手动打开「减少动画」。

## 10. 可调整的地方

- **颜色和主题**：`css/base.css` 顶部的 CSS 变量。
- **道具价格、名称、说明**：`js/state.js` 里的 `SHOP`。
- **星星奖励、金币、经验**：`js/state.js` 里的 `finishLevel`。
- **初始金币和道具**：`js/storage.js` 里的 `createDefaultSave`。
- **家长默认密码**：`js/storage.js` 里的 `parent.password`，或进入家长模式后修改。
- **题库**：`js/questions.js` 或家长模式的自定义题库。

## 11. 设计约定

- 答错不惩罚、不嘲笑，只扣爱心并给出分步提示。
- 爱心用完不是游戏结束，而是回到本关开头，爱心重新充满。
- 每道题答对后都显示讲解。
- 首次通关才发金币和经验，避免重复刷奖励。
- 复习错题答对后净化移除，并给少量正向反馈。
- 所有数据只存在本机，不收集任何个人信息，也没有网络请求。
